# Frontend Migration RFC: Python to React (Historical Feature Proposal)

> [!NOTE]
> **Historical Architecture Proposal**: This proposal was created during exploratory work on the `swa/refresh-pipeline-2025` / `swa/frontend-consolidation` branches. On `master`, the repository maintains the live-rendered single-template architecture (`frontend/dashboard/dashboard_template.html` served by FastAPI at `/`). This document is kept for historical context and future evaluation.

Core Objective: Transition the frontend completely from the legacy Python-assembled static HTML dashboard (frontend/dashboard/) to a single React/Vite single-page application (frontend/react/). The consolidated React app will be served directly by FastAPI at / while consuming dynamic data via GET /api/dashboard.Background & Key IssuesArchitectural Divergence: The master branch relied on legacy Python scripts (build_dashboard.py, splice_dashboard.py) to inject JSON into a static template (dashboard_template.html). The feature branch (swa/refresh-pipeline-2025) introduced a React/Vite frontend that fetches live data from FastAPI.Pipeline Failures: Splicing scripts broke because the React build output replaced dashboard_template.html without retaining the __DATA_JSON__ placeholder required by offline snapshot tools.Directory vs. Route Misconceptions: The coexistence of frontend/dashboard/ and frontend/react/ led to confusion between disk paths and HTTP routes. The app is a single-file SPA served at /, not /react.Architectural DecisionsSingle Source of Truth: frontend/react/ becomes the only frontend directory. frontend/dashboard/ is deleted entirely.Dynamic Serving at /: FastAPI serves the compiled React bundle (frontend/react/dist/index.html) at root (/). No /react route is added.Asset Relocation: team_colors.json moves to frontend/react/team_colors.json, and backend resolution paths are updated accordingly.Build Integrity Verification: Replace deploy-build.mjs with a post-build verification script (scripts/verify-build.mjs) to assert that the bundle contains no un-inlined references, /assets/ dependencies, or internal file path leaks.Nightly Ingest Overhaul: Replace the Python offline HTML splicing steps in scripts/nightly_refresh.ps1 with npm test (scoring parity validation) and npm run build. Remove validate_dashboard.js.Target LayoutPlaintextfrontend/
